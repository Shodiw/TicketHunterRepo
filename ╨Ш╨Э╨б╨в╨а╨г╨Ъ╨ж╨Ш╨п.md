# 🚂 Деплой БЖД Монитора на Railway
## Пошаговая инструкция (занимает ~10 минут)

---

## ШАГ 1 — Получить Telegram Bot Token и Chat ID

### Создать бота:
1. Откройте Telegram → найдите **@BotFather**
2. Напишите `/newbot`
3. Введите название бота (например: `БЖД Билеты`)
4. Введите username (например: `myzd_tickets_bot`)
5. Скопируйте **токен** — строка вида `1234567890:ABCdef...`

### Узнать свой Chat ID:
1. Напишите своему новому боту любое слово (например `привет`)
2. Откройте в браузере:
   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
   ```
   (замените `<ВАШ_ТОКЕН>` на реальный токен)
3. Найдите в ответе:
   ```json
   "chat": { "id": 123456789, ... }
   ```
   Число `123456789` — это ваш **Chat ID**

## ШАГ 2 — Подготовить файлы

Убедитесь что в одной папке лежат 4 файла:
```
📁 bzd_railway/
   ├── monitor.py
   ├── requirements.txt
   ├── Dockerfile
   └── railway.toml
```

---

## ШАГ 3 — Создать аккаунт и проект на Railway

1. Зайдите на **https://railway.app**
2. Нажмите **Login** → войдите через GitHub
   (если нет GitHub — создайте аккаунт, это бесплатно)
3. На главной нажмите **New Project**
4. Выберите **Deploy from GitHub repo**
   - Если папки нет на GitHub — выберите **Empty Project**,
     затем нажмите **+ New** → **GitHub Repo**

---

## ШАГ 4 — Загрузить код на GitHub (если ещё нет)

1. Зайдите на **https://github.com** → **New repository**
2. Назовите репозиторий `bzd-monitor`, нажмите **Create**
3. Загрузите 4 файла кнопкой **uploading an existing file**
4. Нажмите **Commit changes**

---

## ШАГ 5 — Подключить репозиторий к Railway

1. В Railway: **New Project** → **Deploy from GitHub repo**
2. Выберите ваш репозиторий `bzd-monitor`
3. Railway автоматически найдёт `Dockerfile` и начнёт сборку

---

## ШАГ 6 — Установить переменные окружения ⚠️ ВАЖНО

Это самый важный шаг! Без него скрипт не знает что искать.

1. В Railway откройте ваш сервис
2. Перейдите на вкладку **Variables**
3. Нажмите **New Variable** и добавьте по одной:

| Переменная | Значение | Обязательно |
|---|---|---|
| `ROUTE_URL` | URL с pass.rw.by (скопируйте из браузера) | ✅ |
| `TG_TOKEN` | Токен бота от BotFather | ✅ |
| `TG_CHAT_ID` | Ваш Chat ID | ✅ |
| `CHECK_INTERVAL` | `120` (секунды между проверками) | ➖ |
| `LOWER_ONLY` | `1` (только нижние) или `0` (любые) | ➖ |
| `CAR_TYPES` | `3,4` (3=плацкарт, 4=купе) | ➖ |
| `TARGET_TRAINS` | `737Ь,733Б` или пусто (все поезда) | ➖ |

### Как получить ROUTE_URL:
1. Откройте **pass.rw.by** в браузере
2. Введите маршрут (откуда/куда) и дату
3. Нажмите **Найти**
4. Скопируйте весь URL из адресной строки
5. Вставьте как значение `ROUTE_URL`

## ШАГ 7 — Запустить и проверить

1. После добавления переменных Railway автоматически перезапустит сервис
2. Откройте вкладку **Deployments** → нажмите на активный деплой
3. Вы увидите логи примерно такие:
   ```

     БЖД Монитор билетов — серверная версия
   ==================================================
     Интервал:  120 сек

     ✗ Подходящих мест нет
   ```

## Частые проблемы

**Ошибка "ROUTE_URL не задан"**
→ Проверьте Variables, убедитесь что переменная называется именно `ROUTE_URL`

**Telegram не пишет**
→ Убедитесь что написали боту хотя бы одно сообщение до запуска

**"Расписание не загрузилось" в логах**
→ Попробуйте увеличить `CHECK_INTERVAL` до `180`
→ Возможно сайт поменял структуру

**Сборка не запускается**
→ Убедитесь что `Dockerfile` (без расширения!) загружен правильно

## Остановить мониторинг

В Railway → ваш сервис → **Settings** → **Remove Service**
Или просто нажмите **Pause** (кнопка паузы рядом с деплоем)
